Murder Mystery Project
Overview
This project simulates a murder investigation using SQL queries to analyze data and identify the culprit. By investigating crime reports, witnesses, and suspects, the goal is to find the murderer and the mastermind behind the crime.

Key Steps

Identify the Crime: Locate the murder that occurred on January 15th, 2018, in SQL City.
Witnesses: Find two key witnesses based on their locations.
Interview Analysis: Review interviews to gather details about potential suspects.
Suspect Investigation: Use clues like gym memberships and vehicle information to narrow down suspects.
Final Identification: Determine that Jeremy Bowers is the murderer and Miranda Priestly is the mastermind.

Conclusion
SQL queries were used to piece together clues, analyze data, and ultimately solve the murder mystery.
